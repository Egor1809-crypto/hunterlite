# Fictional training client portraits

These 25 portraits were generated individually for LegalHunter on 2026-09-13.
They depict fictional training characters, not real customers. Gender and age
were taken from the existing reference-persona dossiers. The stable slug mapping
is `apps/api/app/services/portrait_catalog.json`.

Original PNG assets are served through Next.js Image optimization at the requested
avatar size. Do not use random remote avatar URLs: the same client should retain
the same face in the directory, dossier and call.
